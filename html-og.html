01 – Das kann reines HTML

Dies ist eine bewusste OG-HTML-Demonstration: kein eigenes CSS, kein JavaScript, keine Bibliotheken, kein Framework und kein Webserver notwendig. Der Browser übernimmt die Standarddarstellung von Überschriften, Listen, Tabellen und Links.

HTML legt die Struktur und Bedeutung fest. CSS gestaltet diese Struktur; JavaScript ergänzt Verhalten. Auch ein Server kann diese einfache HTML-Datei ausliefern, aber HTML selbst benötigt dafür keinen Server.

html

Jeder Knoten ist ein HTML-Element. Browser bilden daraus ein Document Object Model (DOM).
