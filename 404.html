Der Server hat gesucht, wirklich. Unter dieser Adresse liegt aber keine Datei. ← kein Grund zur Panik, nur ein Pfad!

Was ein 404 eigentlich bedeutet

  1. Der Browser schickt eine Anfrage: GET /diese-seite.html
  2. Der Server (hier Vercel) sucht im Projektordner nach genau dieser Datei.
  3. Findet er sie nicht, antwortet er mit dem Statuscode 404 – und liefert stattdessen diese Seite aus.
$ curl -I https://…/gibt-es-nicht.html
HTTP/2 404
content-type: text/html; charset=utf-8

Typische Ursachen: ein Tippfehler in der Adresse, eine umbenannte Datei (bei mir einmal: index.html → 1_index.html – und plötzlich waren alle Links kaputt) oder ein Link auf eine Seite, die erst in Iteration 2 kommt. Wie das kurz vor meiner Präsentation passiert ist, steht im Launch-Review.
