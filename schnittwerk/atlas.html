VORLESUNG 01 · ABLAUFDIAGRAMM

Wie kommt eine Seite zu mir?

Browser und Server tauschen eine Anfrage und eine Antwort aus. Die Animation auf „Über das Portfolio“ spielt diesen Ablauf exemplarisch nach.

BrowserbereitServer

Simulation · Schritt 0 von 3

const antwort = await fetch("content/vorlesungen/03.md");
console.log(antwort.status);

Fünf Umsetzungsideen

  1. Rollen zuordnen — Browser, Webserver und Datei als drei Stationen beschriften.
  2. Anfrage verfolgen — Die bestehende Animation abspielen und dieselbe Anfrage im Netzwerk-Tab wiederfinden.
  3. Architekturen vergleichen — Auf einem Schaubild zeigen, wo Darstellung, Verarbeitung und Daten bei einer statischen Seite liegen.
  4. Skript ausführen — Einen Gruß im Browser erzeugen und den Zeitpunkt der Ausführung markieren.
  5. JavaScript abschalten — Mit dem vorhandenen noscript-Beispiel prüfen, welche Information sichtbar bleibt.

VORLESUNG 03 · ORDNERKARTE

Wo sucht der Browser ein Bild?

Die gleiche Bilddatei hat je nach Ausgangsseite einen anderen relativen Pfad. Dazu gibt es bereits ein eigenes Learning in Kapitel 3.

bar.html
├─ getraenke/elixir.html
└─ bilder/gruen.jpg

Pfad zum Bild ../bilder/gruen.jpg

<!-- aus getraenke/elixir.html -->
<img src="../bilder/gruen.jpg" alt="Grünes Elixier">

Fünf Umsetzungsideen

  1. Bildpfad ablaufen — Von elixir.html eine Ebene hinauf und weiter zu bilder/gruen.jpg gehen.
  2. Navigation testen — In der KopfüBar Hin- und Rücklink aus zwei verschiedenen Unterordnern verfolgen.
  3. Parameter variieren — Dieselbe Zählfunktion mit „B“ und „b“ aufrufen und die Treffer vergleichen.
  4. Reine Funktion prüfen — countBs zweimal mit derselben Eingabe ausführen und das Ergebnis protokollieren.
  5. Funktionen weitergeben — Mit filter und einer Prüffunktion nur passende Dateinamen anzeigen.

VORLESUNG 04 · RECHENBLATT

Wie wird aus einer Eingabe ein Ergebnis?

Der vorhandene Währungsrechner ersetzt das Dezimalkomma und rechnet mit einem festen Übungskurs.

Euro zum Übungskurs 0,86
86,34 €
const text = "100,4";
const dollar = Number(text.replace(",", "."));
console.log((dollar * 0.86).toFixed(2)); // 86.34

Fünf Umsetzungsideen

  1. Dezimalkomma verfolgen — „100,4“ vom Textfeld bis zur Zahl durch die Rechenschritte führen.
  2. Umrechnung umkehren — Dollar → Euro und Euro → Dollar am festen Kurs 0,86 vergleichen.
  3. Grenzfälle prüfen — Leere Eingabe, „abc“ und „12abc“ testen. parseFloat akzeptiert den numerischen Anfang von „12abc“.
  4. Formular beschriften — Ein Label anklicken und zeigen, welches Feld dadurch den Fokus erhält.
  5. CSS untersuchen — In der KopfüBar Abstände und Schrift ändern und den Effekt im Boxmodell erklären.

VORLESUNG 05 · OBJEKTINSPEKTOR

Welche Daten beschreiben ein Beispiel?

Titel, Dateipfad und Kapitel lassen sich in einem Objekt bündeln. JSON macht diese Daten speicherbar.

{ "datei": "gruen.jpg", "kapitel": 3,
  "beschreibung": "Grünes Elixier" }
gruen.jpg · string
const medium = { kapitel: 3, datei: "gruen.jpg" };
const kopie = JSON.parse(JSON.stringify(medium));
console.log(kopie.datei);

Fünf Umsetzungsideen

  1. Medienpass anlegen — Ein Bild als Objekt mit Pfad, Beschreibung und Kapitel darstellen.
  2. JSON lesen — Den Medienpass serialisieren und nach dem Einlesen eine Eigenschaft ausgeben.
  3. Kontakte verwalten — Die offene Kontakte-Aufgabe mit zwei selbst gewählten Testkontakten demonstrieren.
  4. Kapselung zeigen — Ein privates Feld über eine Methode ändern und die Prüfung der Eingabe erklären.
  5. Kopien vergleichen — Ein Objekt mit Spread kopieren und an einer verschachtelten Eigenschaft die Grenze der flachen Kopie zeigen.

VORLESUNG 06 · DOM-BAUM

Wie wird aus Daten eine sichtbare Karte?

Der Browser hält die geladene Seite als Baum im Speicher. Ein Skript kann einen Knoten ergänzen und die Ansicht ändert sich sofort.

article
└─ h3

Grünes Elixier

const titel = document.createElement("h2");
titel.textContent = "Grünes Elixier";
document.body.append(titel);

Fünf Umsetzungsideen

  1. DOM erkunden — Einen Knoten im Baum wählen und das zugehörige Element auf der Seite hervorheben.
  2. Karte aufbauen — Aus dem Medienpass aus Kapitel 5 eine Bildunterschrift erzeugen.
  3. Selektoren vergleichen — Die gleichen Überschriften mit querySelectorAll und mit jQuery auswählen.
  4. Überschriften gestalten — Die Vorlesungsübung als Vorher-nachher-Ansicht mit einer CSS-Klasse zeigen.
  5. Pull Quote erzeugen — Einen markierten Satz auswählen und als hervorgehobenes Zitat in den Artikel einsetzen.

VORLESUNG 07 · EREIGNISPROTOKOLL

Was passiert nach einem Klick?

Die vorhandene Portfolio-Animation reagiert auf Schaltflächen. Am Ereignis lässt sich erklären, welches Element den Ablauf startet.

Mit Tab fokussieren und mit Enter aktivieren.

Ereignisprotokoll bereit
document.querySelector("button").addEventListener("click", event => {
  console.log(event.type, event.currentTarget.textContent);
});

Fünf Umsetzungsideen

  1. Klick verfolgen — Beim Neustart der Portfolio-Animation Ereignistyp und Schaltfläche protokollieren.
  2. Tastatur testen — Dieselbe Schaltfläche per Tab und Enter bedienen und die erreichte Szene vergleichen.
  3. Tabellenzeilen markieren — Die Vorlesungsübung mit Maus und Fokus ausprobieren.
  4. Akkordeon öffnen — Für jede Schicht einen Abschnitt mit verständlichem geöffnetem Zustand anbieten.
  5. Fenstergröße beobachten — Bei resize die aktuelle Breite ausgeben und den Übergang zur mobilen Ansicht zeigen.
