Demo 00 · Der Aufhänger

Wie Apple ein Produkt erzählt.

Auf Apples Produktseiten klappt ein Laptop auf, während man scrollt – vorwärts und rückwärts. Das ist kein Video: Die Scrollposition wählt aus einer Bildsequenz das passende Bild und zeichnet es in ein <canvas>. Hier dieselbe Technik, mit 120 selbst gezeichneten Bildern.

scrollFraction = 0.00 Frame 0 / 119

Wie funktioniert das?

Der Bereich ist viel höher als der Bildschirm, das <canvas> bleibt mit position: sticky stehen. Bei jedem Scrollen rechnet JavaScript aus, wie weit man durch den Bereich ist (0 bis 1), macht daraus eine Bildnummer und zeichnet genau dieses Bild. Apple lädt dafür echte Fotos einer Bildsequenz vor – hier zeichnet eine Funktion jedes Bild selbst. 

// 1. Wie weit bin ich durch den Bereich? (0 … 1)
const rect = buehne.getBoundingClientRect();
const scrollFraction = -rect.top / (rect.height - innerHeight);

// 2. Daraus wird eine Bildnummer
const frame = Math.min(FRAMES - 1, Math.floor(scrollFraction * FRAMES));

// 3. Nur dieses eine Bild zeichnen – im nächsten Animationsschritt
requestAnimationFrame(() => zeichneFrame(frame));

Demo 01 · Fade-in beim Scrollen

Was ist Scrollytelling?

Eine Erzähl- und Gestaltungstechnik, bei der Inhalte und Animationen durch Scrollbewegungen schrittweise sichtbar oder verändert werden.

Schritt für Schritt

Inhalte erscheinen genau dann, wenn sie gebraucht werden.

Du bestimmst das Tempo

Die Scrollbewegung steuert die Geschichte – nicht ein Video.

Bewegung mit Bedeutung

Animation lenkt den Blick auf das Wesentliche, statt nur zu dekorieren.

Wie funktioniert das Fade-in?

CSS versteckt die Elemente zunächst (opacity: 0). JavaScript beobachtet sie mit dem Intersection Observer. Sobald ein Element in den sichtbaren Bereich kommt, bekommt es die Klasse is-visible – und CSS blendet es weich ein. 

// JavaScript: Element beobachten
const beobachter = new IntersectionObserver((eintraege) => {
  for (const eintrag of eintraege) {
    if (eintrag.isIntersecting) {
      eintrag.target.classList.add("is-visible");
    }
  }
});

/* CSS: Ausgangs- und Endzustand */
.reveal            { opacity: 0; transform: translateY(40px); }
.reveal.is-visible { opacity: 1; transform: none; }

01 · HTML

Alles beginnt mit Struktur.

HTML definiert die semantische Struktur und die Inhalte einer Webseite: Überschriften, Absätze, Buttons.

02 · CSS

Dann kommt Gestaltung.

CSS gestaltet Layout, Typografie und Animationen. Scrollbasierte Animationen lassen sich teilweise direkt mit modernen CSS-Funktionen umsetzen.

03 · JavaScript

Dann kommt Verhalten.

JavaScript ermöglicht Interaktionen und steuert komplexere Abläufe – zum Beispiel über die Intersection Observer API.

04 · Zusammenspiel

Und gerade passiert es.

Dieser Abschnitt ist selbst Scrollytelling: HTML liefert die Texte, CSS hält die Grafik fest, JavaScript merkt, welcher Schritt gerade sichtbar ist.

Wie funktioniert die Sticky Section?

Die Grafik hat position: sticky und bleibt deshalb stehen, solange ihr Abschnitt sichtbar ist. JavaScript beobachtet die Textschritte. Erreicht ein Schritt die Bildschirmmitte, schreibt es dessen Nummer in das Attribut data-schritt der Grafik. Was sich dann ändert, legt allein CSS fest. 

/* CSS: Grafik festhalten */
.story__visual { position: sticky; top: 0; }

// JavaScript: aktiven Schritt an die Grafik weitergeben
browser.dataset.schritt = eintrag.target.dataset.schritt;

/* CSS: Aussehen je Schritt */
.browser[data-schritt="2"] .mini--button { background: blue; }

Demo 03 · Bewegen & Skalieren

Der Scrollbalken als Regler.

Hier steuert deine Scrollposition direkt die Animation: Scrolle langsam hoch und runter – die Form wächst, dreht sich und schrumpft wieder. Ganz ohne JavaScript.

view()

Dein Browser unterstützt scrollgesteuerte CSS-Animationen noch nicht – du siehst deshalb die statische Variante. Genau so funktioniert Progressive Enhancement: Die Seite bleibt nutzbar, nur ohne Effekt.

Wie funktioniert das?

Normalerweise läuft eine CSS-Animation über eine Zeitdauer (z. B. 1 Sekunde). Mit animation-timeline: view() ersetzt der Browser die Zeit durch die Position des Elements im sichtbaren Bereich: 0 % = es kommt gerade herein, 100 % = es ist gerade verschwunden. @supports prüft vorher, ob der Browser das kann. 

@supports (animation-timeline: view()) {
  .skalier-demo__objekt {
    animation: wachsen linear both;
    animation-timeline: view();
  }
}

@keyframes wachsen {
  from { transform: scale(0.4) rotate(-20deg); }
  to   { transform: scale(1)   rotate(0); }
}

Demo 04 · Vergleich

Statisch oder gesteuert?

Gleicher Inhalt, zwei Darstellungen. Links ist alles sofort da. Rechts erscheint jeder Punkt erst, wenn du ihn erreichst – das lenkt den Blick, kostet aber auch Zeit.

Statisch

  • Struktur mit HTML
  • Gestaltung mit CSS
  • Verhalten mit JavaScript

Scrollgesteuert

  • Struktur mit HTML
  • Gestaltung mit CSS
  • Verhalten mit JavaScript

Faustregel: Animation nur dort, wo sie etwas erklärt. Wer in den Systemeinstellungen „Bewegung reduzieren“ aktiviert hat, sieht diese Seite deshalb ganz ohne Animationen.
