## Überblick

📘 Jede Änderung an einer Seite besteht aus zwei Schritten: **1. das Element identifizieren, 2. etwas damit tun** (vorl6-1,
Folien 4–8). Für Schritt 1 baut der Browser beim Laden ein Modell der Seite, das **DOM**. Die Vorlesung zeigt, wie man darin Knoten
findet und ändert – und warum das mühsam ist. Die Lösung sind **JavaScript-Bibliotheken**, allen voran **jQuery**: Elemente mit
CSS-Selektoren auswählen, automatisch alle Treffer bearbeiten, Funktionen verketten, Inhalte, Klassen und CSS ändern.
Teil 2 erklärt `each()`, anonyme Funktionen und `$(this)` und endet mit automatischen „Pull Quotes“.

## Lernziele

- Ich kann erklären, was das DOM ist, und eine HTML-Seite als Baum aus Knoten zeichnen.
- Ich kann Elemente mit `getElementById` und `getElementsByTagName` finden und mit `innerHTML` ändern.
- Ich kenne die Verwandtschafts-Eigenschaften `childNodes`, `parentNode`, `nextSibling` und `previousSibling`.
- Ich kann erklären, was eine Bibliothek bzw. ein Framework ist und was jQuery vereinfacht.
- Ich kann mit jQuery Elemente auswählen (`$('#id')`, `$('.klasse')`, `$('a')`) und Inhalte, Klassen und CSS ändern.
- Ich kann mit `each()` und `$(this)` jedes ausgewählte Element einzeln bearbeiten.

## Zusammenfassung

### Teil 1 – Das Document Object Model (vorl6-1, Folien 10–32)

📘 Lädt der Browser eine HTML-Datei, zeigt er sie nicht nur an, sondern merkt sich auch ein **Modell** des HTML: das DOM. Es enthält
alles, was JavaScript braucht, um mit den Elementen zu sprechen. Das DOM selbst ist kein JavaScript, sondern ein **Standard des
W3C** (Folien 10–11). Jeder Tag, jedes Attribut und auch der **Text** sind Knoten im Baum (Folien 12–14).

✏️ Das passt zu meiner Skizze aus Vorlesung 1: Der Browser hat eine Anzeige und ein Dokument (DOM).

📘 **Elemente finden** (Folien 15–20):

- `document.getElementById('ueberschrift')` liefert genau ein Element.
- `document.getElementsByTagName('a')` liefert eine **Liste** aller Links – man braucht eine Schleife.
- Beides lässt sich kombinieren: erst einen Bereich per ID, dann darin alle Tags.

📘 **Verwandte Knoten** (Folien 21–28): `.childNodes` (Kinder), `.parentNode` (Eltern), `.nextSibling` / `.previousSibling`
(Geschwister). Weil auch Leerzeichen und Zeilenumbrüche Textknoten sind, ist das Navigieren „eine ganze Menge Verrenkungen“.

📘 **Inhalt ändern** (Folien 29–32): Neue Knoten Stück für Stück zu bauen ist harte Arbeit. Einfacher ist `innerHTML`: Es liest den
HTML-Inhalt eines Elements und kann ihn auch ersetzen.

### Teil 2 – Das Problem mit dem DOM und die Lösung: Bibliotheken (Folien 33–44)

📘 Das DOM ist mächtig, aber umständlich: viele Schritte, kein einfacher Weg zu allen Elementen einer **Klasse**, und Browser setzen
es unterschiedlich um (Folien 33–35). Eine **JavaScript-Bibliothek** ist eine Sammlung fertiger Funktionen für immer
wiederkehrende Aufgaben (Folien 36–37). Das Skript nutzt **jQuery**: klein, browserübergreifend getestet, große Entwicklergemeinde,
viele Plug-ins (Folien 38–40). Man lädt die Datei herunter oder bindet sie per CDN ein, **vor** dem eigenen Code (Folien 41–44).

📘 Ein **Framework** stellt Dienstfunktionen bereit, die zwischen Browser und eigenem Code vermitteln. Die innere Logik ist egal –
wichtig ist, wie man die Methoden aufruft und welche Parameter sie brauchen (Folien 45–47).

### Teil 3 – jQuery: auswählen, durchlaufen, verketten (Folien 50–78)

📘 Herzstück ist die Funktion `$()`. Sie nimmt einen **CSS-Selektor** und liefert ein jQuery-Objekt mit allen Treffern
(Folien 55–62):

| Aufgabe | DOM | jQuery |
|---|---|---|
| Element per ID | `document.getElementById('meldung')` | `$('#meldung')` |
| alle Links | `document.getElementsByTagName('a')` | `$('a')` |
| alle mit Klasse | gibt es im DOM nicht direkt | `$('.untermenue')` |

📘 Dazu kommen fortgeschrittene Selektoren – Nachkommen (`#navi a`), Kinder (`body > p`), Geschwister (`h2 + div`), Attribute
(`a[href^="http://"]`) – und Filter wie `:even`, `:odd` oder `:has()` (Folien 64–74).

📘 Zwei Vorteile gegenüber dem DOM (Folien 76–78):

- **Automatische Schleifen:** `$('#diashow img').hide()` versteckt **alle** Bilder, ohne selbst eine Schleife zu schreiben.
- **Verkettung:** Fast jede Methode gibt wieder ein jQuery-Objekt zurück, also kann man weiterschreiben:
  `$('#popUp').width(300).height(300)`.

### Teil 4 – Seiten mit jQuery verändern (Folien 79–105)

📘 Die wichtigsten Werkzeuge:

- **Inhalte:** `.html()` wie `innerHTML`, `.append()` / `.prepend()` am Ende bzw. Anfang einfügen, `.before()` / `.after()`
  davor bzw. dahinter, `.remove()` entfernt die Auswahl (Folien 79–87)
- **Klassen:** `.addClass()`, `.removeClass()`, `.toggleClass()` – z. B. ein Knopf, der das ganze Design umschaltet (Folien 89–93)
- **CSS direkt:** `.css('background-color')` liest, `.css('font-size', '200%')` setzt, ein Objekt-Literal setzt mehrere Werte auf
  einmal (Folien 94–103)
- **Attribute:** `.attr()` liest und setzt, `.removeAttr()` entfernt (Folien 104–105)

> 🤖 **Verbindung zu diesem Portfolio:** Der Farbwähler unten rechts macht genau das, was Folie 93 mit `toggleClass` zeigt – nur ohne
> jQuery. Ein Klick setzt `document.documentElement.dataset.farbe`, und CSS übernimmt den Rest.

### Teil 5 – `each()`, anonyme Funktionen und `$(this)` (vorl6-2, Folien 3–10)

📘 Will man mit **jedem** ausgewählten Element etwas Eigenes tun (z. B. die URL jedes externen Links auslesen), nimmt man
`$('selektor').each(function() { … })`. Die übergebene **anonyme Funktion** läuft für jedes Element einmal. Am Ende stehen drei
Zeichen: `}` beendet die Funktion, `)` die `each`-Klammer, `;` die Anweisung (Folien 3–6).

📘 Innerhalb der Funktion zeigt **`this`** auf das aktuelle Element (ein DOM-Element). Mit **`$(this)`** macht man daraus ein
jQuery-Objekt und kann wieder jQuery-Methoden nutzen (Folien 7–10). Hier taucht `this` aus Vorlesung 5 wieder auf.

## Beispiele

📘 DOM: Überschrift finden und ändern, Eltern und Geschwister (vorl6-1, Folien 12, 18, 26–27, 32):

```html
<body class="home">
  <h1 id="ueberschrift">Eine Überschrift</h1>
  <p>Ganz <strong>wichtiger</strong> Text</p>
  <script>
    const ueberschrift = document.getElementById('ueberschrift');
    ueberschrift.innerHTML = 'Hier war JavaScript am Werk!';
    console.log(ueberschrift.parentNode.tagName);   // BODY
    console.log(ueberschrift.nextSibling);          // #text – der Zeilenumbruch!
  </script>
</body>
```

📘 Dasselbe mit jQuery – plus Verkettung und Klassen (Folien 59, 77, 90–93):

```html
<script src="js/jquery.js"></script>
<script>
  $(document).ready(function () {
    $('#ueberschrift').html('Hier war jQuery am Werk!');
    $('#popUp').width(300).height(300);
    $('a[href^="http"]').addClass('externerLink');
    $('#stilAendern').click(function () {
      $('body').toggleClass('alternativerStil');
    });
  });
</script>
```

📘 `each()` mit `$(this)`: aus allen externen Links eine Liste bauen (vorl6-2, Folien 9–10):

```html
<script>
  $('a[href^="http"]').each(function () {
    const adresse = $(this).attr('href');
    $('#linkliste').append('<li>' + adresse + '</li>');
  });
</script>
```

🤖 Ohne Browser zum Ausprobieren: Das Prinzip von `each` – eine anonyme Funktion läuft für jedes Element einmal:

```js
const links = ["https://dhbw.de", "kapitel.html?nr=3", "https://github.com"];
links.forEach(function (adresse, i) {
  if (adresse.startsWith("http")) {
    console.log(i + ": extern → " + adresse);
  }
});
```
