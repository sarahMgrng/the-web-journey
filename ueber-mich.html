Mein Pitch

  • Ich lerne, indem ich baue. Dieses Portfolio ist ohne Framework geschrieben: HTML, CSS und JavaScript, genau das, was in der Vorlesung vorkommt. Mein Schwerpunkt ist Scrollytelling.
  • Ich automatisiere. Auf meinem eigenen Server läuft n8n. Nach jeder Vorlesung legt ein Workflow ein GitHub-Issue mit Checkliste an, ein lokales Sprachmodell (Ollama) ergänzt Kontrollfragen.
  • Ich mache sichtbar, woher Wissen kommt. Jeder Absatz im Portfolio ist gekennzeichnet: Skript, eigene Notiz, KI-Erklärung oder offene Frage. So sieht man, was ich selbst verstanden habe.

Wege zu meinem Portfolio

Dieselbe Website, fünf Wege dorthin – jeder zeigt einen anderen Teil davon, wie das Web funktioniert.

  • 01 · Online · https:// Website auf Vercel Gehostet, über HTTPS, auch am Handy. Zugang per Leselink.
  • 02 · Datei · file:// index.html per Doppelklick Aus der ZIP, ohne Server und offline. Kapitel kommen aus js/inhalte.js.
  • 03 · Lokal · http://localhost:5500 Eigener Webserver python3 -m http.server 5500 – Kapitel kommen per fetch() aus den .md-Dateien.
  • 04 · Ursprung · nur HTML html-og.html Dieselbe Basis ohne CSS und JavaScript – der Ausgangspunkt.
  • 05 · Code · GitHub Quellcode (Abgabestand) Branch abgabe-final mit README, Roadmap und Pull Request. Privat – Zugang per Einladung.
